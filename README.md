# Love Feast — V1 🌴💌

A playful matchmaking party-game prototype.

## Files

- `index.html` — the website structure
- `style.css` — design and responsive layout
- `script.js` — buttons, room-code demo, lobby, and Round 1

## Important

This V1 is a **browser-only prototype**. A Feast created on one device is not actually shared with other devices yet.

The next development step is to add a free online database/backend so a host can create a room and multiple friends can join the same room in real time.

## Run it

You can simply open `index.html` in a browser.

For free public hosting, GitHub Pages can publish static HTML/CSS/JavaScript files from a GitHub repository.
